Sequences and calendar campaigns

Sequences carry a prospect across Gmail and the connected social channels. Calendar campaigns are a separate campaign type that sends Google Calendar invitations and measures RSVP. Each path needs only the connections it uses.

Sequence path

Coordinated outreach across email and social channels.

Build one ordered sequence from Gmail, LinkedIn, and WhatsApp steps. A sequence can also be social-only; Google Workspace is required only when it contains a Gmail step.

  1. Step 1

    Email

    A Gmail step opens the sequence from your own mailbox.

  2. Step 2

    Connect

    A LinkedIn connection request follows, with an optional note.

  3. Step 3

    Message

    A LinkedIn or WhatsApp message continues the conversation.

  4. Step 4

    Reply

    When a reply is detected, it appears in the Tantra inbox and the sequence stops for that contact.

Each channel in a sequence sends from a connected, ready sender account. LinkedIn and WhatsApp accounts are included in Pro and Scale.

Explore LinkedIn→Explore WhatsApp→
Calendar path

Webinar attendance attributed to calendar invitations.

Link a Zoom or WebinarGeek session to a Tantra calendar campaign. Contacts who RSVP Yes or Maybe can be registered for the webinar, and synced attendance shows which invitees joined.

  1. Step 1

    Invite

    A Google Calendar invitation goes out.

  2. Step 2

    RSVP

    The contact responds yes, no, or maybe.

  3. Step 3

    Register

    A Yes or Maybe RSVP can register the contact for the linked webinar.

  4. Step 4

    Attribute

    Synced attendance shows which invitees joined.

Webinar catalog and attendee sync are user-triggered.

Credential and access controls

Tantra connects to each provider through the method that provider supports: delegated Google service accounts, provider API credentials, linked social accounts, revocable Tantra API keys, and verified HTTPS endpoints.

Credential storage by type

Secrets are encrypted or hashed according to their credential type and are not displayed again when the product does not need to return them.

Revocable access

Disconnect provider credentials, remove channel accounts, revoke API keys, or disable webhook endpoints from Tantra.

Documented sync behavior

Each integration page states whether data is event-driven, periodically reconciled, or refreshed only when you request a sync.
